Restore single-line set_reference_projects import in server.py

Fixes the isort CI job.

Commit 6bbe609 ("docs(pr_info): fold step 4 docs into step 3") was intended to
touch only pr_info/steps/*.md, but it also carried a stray reformatting of the
set_reference_projects import in src/mcp_workspace/server.py, rewrapping it
into a parenthesized multi-line form with a trailing comma. The isort job
(isort --check --profile=black --float-to-top src tests) rejects that form and
fails on this single file.

Revert that hunk so the import is one line again. This restores server.py to
its exact pre-6bbe609 content (blob 454c9c9), the form that shipped through the
preceding merged commits. server.py is listed under "Unchanged (deliberately)"
in pr_info/steps/summary.md for issue #268 and appears in none of the three
implementation steps, so this PR should leave it untouched.

No configuration change is needed: pyproject.toml's [tool.isort] settings
(profile = "black", line_length = 88, float_to_top = true) already match both
the CI invocation and tools/format_all.sh.
