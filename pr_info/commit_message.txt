fix(git): use line-based filter for show <blob> search (content, not diff)

git_show with a colon argument (e.g. HEAD:README.md) returns plain file
content, not a diff, so filter_diff_output found no hunks and always
reported "No matches". Add filter_content_output, a line-based grep with
context that reuses the sibling filters' no-match and invalid-pattern
messages, and select it in git_show when has_colon is set. git_diff is
unchanged. Covered by unit tests for the new filter and a real-repo
integration guard.
